Perform a Root Cause Analysis (RCA) and propose a technical fix for the following scenario:

[CONTEXT]
A developer removes `'unsafe-eval'` from the Content Security Policy (CSP) headers in `vercel.json` and a Node.js Express server to improve security. 

[PROBLEM]
Immediately after deployment, the local development environment (Vite HMR) breaks, and several browser extensions start throwing errors in the console.

[TASK]
1. Identify why 'unsafe-eval' was necessary for development.
2. Propose an architecture that maintains security on Production while allowing development tools to function.
