Task: Implement the 'DriftCorrection' logic for the CoVibe YouTube Player.
Context:
- CoVibe is a synchronized music listening app.
- We receive 'serverTime' and 'localTime' via WebSockets.
- The 'drift' is calculated as the difference between the local player's current time and the leader's time.

Requirements:
- Follow the guidelines in GEMINI.md:
  - If drift < 250ms: Do nothing (smooth playback).
  - If 250ms <= drift <= 800ms: Adjust 'playbackRate' to 0.95x or 1.05x to catch up/slow down seamlessly.
  - If drift > 800ms: Perform a hard 'seekTo' to the correct timestamp.
- Implement a function 'calculateCorrection(currentDrift: number): CorrectionAction'.
- Define 'CorrectionAction' type.

Output: Clean TypeScript implementation of the correction logic.
