### 2. Sync Action Calculation Function
```typescript
function calculateSyncAction(clientTime: number, serverTime: number, drift: number) {
    if (drift < 250) return 'ignore';
    if (drift < 800) return 'adjust_rate';
    return 'seek';
}
```

### 3. Complete Usage Example

```typescript
// Example: Simulating a trip room synchronization scenario

const tripRoom: TripRoom = {
    id: 'trip-123',

    passengers: ['user-001', 'user-002', 'user-003'],
    currentVideoId: 'dQw4w9WgXcQ',
    isPlaying: true,
    serverTime: Date.now()
};

// Simulate client time with drift
const clientTime = Date.now() - 600; // 600ms behind server
const drift = clientTime - tripRoom.serverTime;

// Calculate appropriate sync action
const action = calculateSyncAction(clientTime, tripRoom.serverTime, drift);

console.log(`Drift: ${drift}ms`);
console.log(`Action: ${action}`);

// Expected output:
// Drift: -600ms
// Action: adjust_rate
```

### 4. Decision Logic Summary

| Drift Range | Action | Description |
|-------------|--------|-------------|
| < 250ms | `ignore` | Minimal drift, no action needed |
| 250-800ms | `adjust_rate` | Moderate drift, adjust playback rate |
| ≥ 800ms | `seek` | Large drift, seek to sync position |

### 5. Key Considerations

- **Drift calculation**: `drift = clientTime - serverTime` (negative = behind, positive = ahead)
- **Threshold design**: The two-tiered approach (ignore vs adjust vs seek) prevents unnecessary seeks for minor drift
- **Performance**: Using `ignore` for small drifts saves network bandwidth and processing

This implementation demonstrates proper synchronization logic for a multi-user video playback system.
