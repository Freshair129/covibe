Perform a Root Cause Analysis (RCA) and propose a technical fix for the following scenario:

[CONTEXT]
A benchmarking script runs on Windows. It captures AI output via a streaming API. Occasionally, the AI generates emojis (e.g. 😀) or complex Unicode characters.

[PROBLEM]
The Python script crashes with a `UnicodeEncodeError` when trying to print these characters to the Windows terminal.

[TASK]
1. Identify the default encoding issue on Windows.
2. Propose a system-level fix in Python to ensure the script is resilient to any Unicode character.
